# 首轮模拟训练结果 — 2026-09-27

已完成一轮 PPO 训练并保存可运行模型。模型只控制模拟按键的按住/松开，使用位置数值及历史差分观测，没有读取鱼的隐藏目标或真实速度。

## 训练记录

| 项目 | 本次结果 |
|---|---|
| 模型 | PPO，Actor/Critic 各两层 128 单元，无注意力 |
| 观测 | 16 帧 × 18 项 + 6 项配置 = 294 维 |
| 训练规模 | 2,002,944 个决策，6,966 次钓鱼尝试 |
| 实际运行时间 | 176.4 秒（Ryzen 7 7800X3D，CPU） |
| 训练种子 | 42；本次仅一轮训练种子 |
| 训练范围 | 55 种目录鱼、最终等级 0–10、无渔具 |
| 训练阶段 | 前 25 万步低难度/等级 10；到 100 万步增加难度；后续完整鱼池 |
| 最佳模型 | `runs/20260927_ppo_v1/best.zip`，200 万步的开发集检查点 |

训练器按完整 rollout 完成更新，因此实际步数略高于 200 万。最佳模型是在开发集上的评估节点保存的；没有用保留测试集重新挑选模型。

## 同一批 1,000 条保留测试轨迹

测试种子为 2,000,000–2,000,999，与训练及开发集分开。鱼种按目录均匀采样，等级均匀采样 0–10，无渔具。三个控制器使用相同种子和初始配置；鱼运动随机流独立于控制动作，可进行配对比较。这不是自然游戏钓场中鱼种出现概率的估计。

| 控制器 | 捕获成功率 | 95% Wilson 区间 | 完美捕获/总尝试 |
|---|---:|---:|---:|
| 简单预测规则 | 68.2% | 65.2%–71.0% | 34.1% |
| 8 步预测 MPC | 85.3% | 83.0%–87.4% | 40.9% |
| 首轮 PPO | **85.9%** | 83.6%–87.9% | 39.2% |

PPO 与 MPC 只差 0.6 个百分点，本次结果不足以证明 PPO 稳定优于 MPC。两者都明显高于这里实现的简单预测规则。这些指标不能代表现有图像识别助手在实际游戏中的成功率。

## PPO 按难度拆分

| 难度 | 次数 | 捕获成功率 |
|---|---:|---:|
| <40 | 177 | 100.0% |
| 40–69 | 455 | 98.7% |
| 70–89 | 258 | 80.6% |
| ≥90 | 110 | 22.7% |

高难度和小绿条仍是明显弱项。下一步可在新的开发集上比较更长训练、困难鱼采样和历史/奖励设置；这些建议尚未实施。继续调参时应另留新的最终测试种子，避免把这批测试变成选模集。

## 验证与复现

- 25 组鱼类型/渔具、每组 400 帧，Python 鱼与绿条数值更新和 Pufferdle 固定版本的 JavaScript 参考更新一致，合计 10,000 帧。
- Gymnasium 与 SB3 环境检查通过；随机种子重现、观测不包含隐藏状态、边界、按键方向、终止条件和奖励检查通过。
- 原始逐回合报告：`final_evaluation.json`、`final_rule_evaluation.json`、`final_mpc_evaluation.json`，均位于本次实验目录。
- 模型、参数、软件版本、训练状态、学习曲线和训练日志保存在同一目录。打开训练页面可加载最佳 PPO 权重演示，或继续训练。

当前验证范围是 Pufferdle 数值模型和本地训练工具；实际游戏版本、图像测量、输入延迟与丢帧尚未纳入。
